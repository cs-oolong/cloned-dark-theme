# Cloned Dark Theme

A vibrant dark theme for [Zed](https://zed.dev), cloned from Gemini chat code
blocks and tuned by hand.

![background `#121214`](https://img.shields.io/badge/background-%23121214-121214)

## Palette

| Token | Color |
|---|---|
| types | `#FF5555` red |
| strings | `#FF00FF` fuchsia |
| functions / constructors | `#00D4FF` cyan |
| keywords | `#5C7CFF` vivid blue |
| special functions | `#FF9500` orange |
| numbers | `#BF5AF2` purple |
| comments | `#5C6370` muted gray |
| foreground | `#E1E1E6` |
| background | `#121214` |

## Installation

Once published, search for **Cloned Dark Theme** in Zed's extension page
(`zed: extensions` from the command palette).

For local development, use `zed: install dev extension` and point to this
directory.
